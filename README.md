# Airbnb Listings EDA

Exploratory analysis of an Airbnb `listings` dataset, in one Jupyter notebook. Group
project for a data analysis course.

- `GROUP_1_AIRBNB.ipynb` starts with basic exploration of the listings, then moves into
  a more open-ended question the group picked.
- `listings.csv` is the raw data.

Run it:

```bash
pip install pandas numpy matplotlib seaborn jupyter
jupyter notebook GROUP_1_AIRBNB.ipynb
```
